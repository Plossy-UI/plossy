
# Plossy

A lightweight, modern CSS and Vanilla JavaScript UI framework.

## Installation

```bash
npm install plossy
```

## Features

- Modular UI components
- CSS utilities with `pl-` prefix
- Responsive layouts
- Vanilla JavaScript
- Bootstrap compatibility
- Custom themes
